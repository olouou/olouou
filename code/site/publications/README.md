# Dossier Publications — GEOMETRE TOPO

Ce dossier reçoit les images et visuels destinés aux publications Facebook via Composio.

## Convention de nommage (obligatoire)

- Pas d'espaces, d'accents, de virgules ni de caractères spéciaux dans les noms de fichiers.
- Utiliser des tirets ou underscores, tout en minuscules : ex. `leve-gnss-bifrequence.jpg`, `bornage-terrain-vegetation.jpg`.
- Extension en minuscules (.jpg, .jpeg, .png).

## URL publique à utiliser pour Composio

```
https://raw.githubusercontent.com/olouou/olouou/main/code/site/publications/<nom-du-fichier>
```

Ce dossier est géré automatiquement par Claude : lorsqu'une image est fournie pour une publication Facebook, elle est déposée ici avant d'être transmise à Composio.
